# ammaraamirkhan.com

Personal portfolio. Plain HTML, CSS and JS, hosted on GitHub Pages.

## Editing

- `config.js` holds every photo path and contact link. Swap a photo by dropping the file in `images/` and updating its `src`.
- Missing photos show a purple placeholder that names the file the page expects.
- Links set to `""` (email, resume) are hidden until you fill them in.
- Copy lives in `index.html`. Colors and type are tokens at the top of `style.css`.
